# akiya-watch 使い方メモ（README＝文書の入口）

**正本宣言**: 仕様の正本は `docs/SPEC.md`、決定の理由は `docs/DECISIONS.md`、時系列は `docs/WORKLOG.md`、バグは `docs/BUGLOG.md`、監視URLと閾値は `urls.yaml`。本書は人間向けの短い操作メモと文書の地図。最終更新は `git log -1 -- docs/README.md` を見る。

## これは何か
静岡県東部〜伊豆〜富士周辺の不動産情報を毎朝自動で集め、1枚のWebページにまとめるツール。
4つのタブ: **更地**（再建築できそうな安い土地）／**家付き土地**（古家・中古戸建・空き家）／
**キャンプ場土地**（2号店用の広い山物件。沼津IC起点1〜1.5時間圏）／**賃貸**（激安賃貸）。
サイト数は `SOURCES.md`（自動生成）を見る。

## 毎日の使い方
1. **開く**: `https://neguracg.github.io/akiya-watch/reports/index.html?u=<自分のキー>`
   （キーは ken / yumiko / ayako。`?u=` を付けると★・非表示が端末をまたいで保存される）
2. **見る**: 上のタブで切替 → 列見出し（スマホは絞り込みチップ）で絞り込み・並べ替え → 「詳細」で元サイトへ
3. **記録する**: ☆で★（お気に入り）、「非表示」で一覧から消す（下の「非表示にした物件」から戻せる）

クロールは GitHub Actions が毎朝 07:00 JST ごろ自動実行し、結果を自動で公開する。PCを起動しておく必要はない。
IT初心者向けの配布用マニュアルは `docs/manual/物件さがしツール_かんたん説明.pdf`。

## 開発者向けコマンド
| やりたいこと | コマンド | 注意 |
|---|---|---|
| 表示ロジックを直した見た目を数十秒で確認 | `py watch.py --rebuild` → `reports/_preview.html` | クロールなし。**公開レポートには一切触らない** |
| 1サイトだけ試走 | `py watch.py --only=<idの部分一致> --dry-run` | `--dry-run` はスナップショット更新なし |
| 公開レポートを今すぐ作り直す | `gh workflow run daily.yml` | 夜間cronと同じ全クロール（約30分）。pushしただけでは公開ページは変わらない |
| フルクロール（ローカル） | `py watch.py` | 本番と同じ成果物をローカルに書く（通常は不要） |

## 設定ファイル `urls.yaml`（たまに触る）
- `sites:` … 監視対象。**URLの追加・変更は必ず Claude Code に「実測して変更案を出して」と頼む**（記憶で書くと存在しないURLが混ざる。手順は `CLAUDE.md`）
- `filters:` … 判定の閾値（価格上限・面積下限・注意/本命キーワード・除外エリア）。画面の初期値になる
- `sources_extra:` … 巡回しないが記録しておくサイト（bot対策・JS描画で保留中のもの）
